# 结构与取舍

Electron 透明窗口负责显示，Windows 跟随组件负责位置；渲染页面通过应用内协议调用 dispatcher，不启动 HTTP 服务器。MCP（模型上下文协议）工具通过本机命名管道访问正在运行的挂件。

官方额度链路：`codex-location` → 已安装且签名有效的官方 `codex.exe` → `app-server` 的 `account/rateLimits/read` → `quota-live` → 额度卡与 `rin_quota`。

程序发现检查正在运行的 Codex、Windows 应用包和官方本地安装目录。只缓存当前进程内已验证路径；路径消失或程序退出后重新发现。不会保存带版本哈希的绝对路径，也不会修改 Codex 默认模型或账号权限。`RIN_CODEX_EXECUTABLE` 可指定候选，但仍检查 OpenAI 签名。

刷新间隔与失败退避使用单调时钟，采样时间使用 UTC 时间戳，界面按本地时区显示。切换时区本身不等于修改系统时钟。失败时保留上次真实样本、原采样时间和旧数据标记；账号变更后不混用缓存。

本机会话统计读取 Codex 的本地观测记录，用于会话/项目用量展示；它不等于官方订阅额度，也不是完整账单。窗口可能只返回一种额度，缺少的类别不会补零。

代码、Electron 和用户数据分开存放。默认数据目录为 `CODEX_HOME/codex-rin-companion`，支持 `RIN_HOME`；兼容旧环境变量 `WHALE_HOME`，同时设置时前者优先。独立版不自动导入旧挂件数据。

本轮保留原有窗口、角色导入、音效和 API 模式实现，避免重写已使用的交互。内部仍有 whale/dsh 名称，它们是兼容标识；不影响新插件身份。主题目前只有图片和 JSON 台词，不引入新的主题框架。

官方 CLI 协议和桌面安装结构仍可能变化。自动发现解决路径更新问题，不能保证所有未来版本零维护。发现不兼容时应显示错误码，修复单一适配层。
